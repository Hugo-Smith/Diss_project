# Dissertation Project – Full-Stack Web Application
This repository contains the source code for my MSc dissertation project – a full-stack web application built with React (frontend), Flask (backend), SQLAlchemy (ORM), and PostgreSQL (database).
The project was developed over 2.5 months and includes research, requirements gathering, and full implementation of core features using best practices.

## Project Overview
The application showcases a modern web development stack, demonstrating seamless integration between a Python backend and a JavaScript frontend.
It emphasizes code quality, scalability, and maintainability.

**Key features include:**
- React frontend with reusable components and state management

- Flask backend with secure routes and input validation

- SQLAlchemy ORM for database interactions

- PostgreSQL database for reliable data storage

- Form validation and authentication best practices

- Security considerations such as password hashing and protection against common web vulnerabilities (e.g., XSS, CSRF)

 ## Motivation
This project was created as part of my MSc dissertation, aiming to demonstrate my understanding of full-stack software engineering concepts, problem-solving skills, and ability to deliver a complete, functioning application from scratch.

 ## Technologies Used
